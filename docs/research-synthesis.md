# 相互監視×アプリロック iOSアプリ構想 統合分析（2026-07-03）

調査3系統（技術実現可能性 / 競合・課金 / TikTokマーケ）の統合。個別レポートは同ディレクトリの final_report.md（競合）および各エージェント出力を参照。

## 1. 全体結論

原案「互いの利用時間を監視して特定アプリをロックし合う」は、**iOSでは原型のままでは作れない**。ただし成立する再設計形が実在アプリで実証されており、その形に落とすと原案の魅力（見られている緊張感・強制力・バイラル性）はほぼ温存できる。市場は「友達承認型ロック」が2025年後半から立ち上がり始めた直後で、全プレイヤーが小粒。**「見知らぬ人とのマッチング」は英日18種以上のキーワード探索でも未発見の空白**であり、そこが差別化の芯になる。

## 2. 技術・規約が決めるコンセプトの形

できないこと（iOS）:
- 正確なアプリ利用時間（分数）を端末外に送ること。DeviceActivityReport extensionはネットワーク禁止＋App Groups経由でもextension→アプリ方向の受け渡し不可（Apple公式回答、iOS 16〜26一貫）。
- 他人の端末を遠隔ロックすること。APIが存在しない。
- 契約面: ADPLA 3.3.3(P)が「他の成人の端末管理」「利用データの本人・家族外共有」を明文禁止。

できること（実証済みパターン = LockPact / Friend Controls / UseLess）:
- DeviceActivityMonitorのthreshold通知で「30分/1時間超え」等の近似バケットを検知しサーバー報告（同時監視20個まで・配信品質に難、実機検証必須）。
- ロックは各自の端末でローカル実行（ManagedSettingsStore）。サーバーから受けた条件（グループの承認状況）に基づき自分自身をロックする。
- 共有するのは「コミット達成/違反フラグ」「しきい値超過」「ロック状態」「解除リクエスト」のみ。LockPactは "screen time data never leaves your device" を売りにしており、この制約は逆にプライバシー訴求になる。
- 認可は本人がいつでも取消せる＝技術では縛れない。強制力はソーシャル/インセンティブ設計で担保する。
- FamilyControls entitlementは個別審査（数日〜4.5週間）。マッチング機能はGuideline 1.2のUGC要件（通報・ブロック機能必須）。

## 3. プロダクト設計の提案

**マッチング単位は1:1でなく4〜6人の匿名スクワッド。**見知らぬ人の離脱・無反応を定足数投票で吸収でき（解除承認が1人不在でも回る）、みんチャレの5人匿名グループ（165万人・月500円）が日本で、UseLessのグループ投票がグローバルで実証済み。

**マッチング軸: ターゲットアプリ × 目標強度 × 活動時間帯。**時間帯は嗜好でなく機能要件——解除リクエストへの応答レイテンシを下げるには起きている時間が重なる相手が必要。原案の「時間帯でマッチング」は技術的にも正しい直感。

**コアループ:** 各自がコミット（例: TikTok 1日30分まで）→ threshold超過で自動ロック＋スクワッドに違反通知 → 延長したければスクワッドに申請 → 投票で承認/拒否 → 週次リーダーボードとストリーク。

**安全設計:** 匿名ハンドル、通報・ブロック（審査必須要件）、初期はフリーテキストDMなし（定型リアクションのみ）でモデレーション負荷を回避。招待コードでの友人ペアリングも併設（審査リスクの低い基本線）。

**リテンション留意（BeRealの教訓: 日次開封率9%まで失速）:** 罰と監視のUXは離脱を内蔵する。ストリーク・称号・スクワッドの共同達成など正の報酬系を同格で設計する。

## 4. 課金設計（推奨）

市場相場: サブスク月$4〜10（中央値$5.99）、年$25〜60、日本勢は月500〜600円。ハードペイウォールはほぼ存在せず、ソーシャル機能は無料開放が定石（JomoはSquadsを無料開放しグロースエンジン化）。天井はOpal（月$19.99、11人でARR $10M）。

**推奨構造（3層）:**
1. **無料 = ソーシャルコアループ全部**（マッチング、スクワッド1つ、ロック1ルール、承認投票、ストリーク）。ネットワーク型はマッチング流動性が命。無料を痩せさせると相手がいなくなり有料価値ごと消える。
2. **サブスク 月$5.99前後 / 年$29.99〜39.99（日本 月600〜800円）+ ライフタイム$79.99前後** = 個人深化機能: 複数スクワッド、複数アプリグループ・カスタムスケジュール、Strict/Monkモード、詳細分析、プロフィールカスタム、優先マッチング。
3. **緊急解除チケット（少量課金）**: Brickの「Emergency Unbrick 5回」、Refocusの「$1リセット」の前例あり。ただし**課金解除してもスクワッドに通知が飛ぶ（買って逃げたことが見える）**設計にして社会契約を守る。この瞬間自体がUGCネタになる。

**デポジット/罰金型は初期はやらない。**Pact（FTCから約$95万返金命令・2017閉鎖）、stickK（賭け金$17M扱って収益$435K未満）の前例が示すのは、罰金経済圏は逆選択・報酬希薄化・決済オペ破綻の三重欠陥を持つこと。個人開発でチャージバック運用と消費者保護対応を抱えるのは危険。やるならフェーズ2でForfeit方式（Stripe外部決済、実証済み）をオプトイン・プレミアムとして。日本ではみんチャレ型のBtoB（自治体・健保）が後期の選択肢。

## 5. TikTokマーケ

- 実態: Opalもone secも主エンジンは**UGC風の有料広告**（Opal月商約40万ドルは第三者分析）。オーガニックはクリエイティブ探索として回し、当たった型を広告化する二段構え。
- 追い風: #lockedin（64.8万投稿）をTikTok公式がNext 2026トレンドに掲載。カテゴリは拡大期。
- プロダクト内蔵のUGCモーメント: 「見知らぬ人に延長申請→拒否される」ドラマ、Walk of Shame型リーダーボード、「課金で逃げた」通知。UseLessの懇願動画→拒否は既に1本の動画として成立している。
- 「TikTokをロックするアプリをTikTokで宣伝する」皮肉は致命的でない（Opalが逆手に取った前例）。誇大効果訴求（○%減少等）だけは裏付け必須。
- 市場: 強いコンセプトのまま出すなら英語圏が素直。日本は相互監視への抵抗が強く（豊明市条例に6割反対）、出すなら「一緒に頑張る自習室」トーンへ翻訳。#勉強垢（再生3.3億回）が導線。

## 5.5 ロックモデルの決定（2026-07-04追記）: Duolingo型 earn-access

Duolingoの「その日のレッスンをクリアするまで他アプリを制限」（ShieldConfiguration extensionによるカスタムシールド）を範型とする。「時間超過で罰」より優れる点:
1. タスク完了は自アプリ内のバイナリ条件 → threshold通知の遅延/早期発火バグにコアループが依存しない
2. スクワッド共有データが「コミット完了フラグ」＝完全にアプリ内データ → ADPLA 3.3.3(P)に一切抵触せず、Screen Time API用途は純粋なロックのみ（Forest/Freedom/Duolingoが通している使い方）
3. 「罰と監視」でなく「クリアして取り戻す」の達成文法 → BeReal型離脱リスクの緩和

ソーシャル層: スクワッドに完了/未完了とロック状態が見える。免除申請は投票。シールド画面に「スクワッドの3人はもう完了済み」を表示 → 画面自体がUGC面、監視キャラ＝スキン課金の置き場所。
タスク種別の優先順: アプリ内フォーカスセッション（最堅牢）＞写真検証（スクワッドが判定役）＞HealthKit＞他アプリのポジティブ利用threshold（精度難）。他社アプリの達成状況（Duolingoレッスン完了等）を条件にする公開APIは存在しない。
制約: シールドUIはテンプレ差し替えのみ（アイコン/タイトル/サブタイトル/ボタン最大2つ）。shield actionから自アプリを直接開けない → 通知経由ワークアラウンドの実機検証がPoC最優先項目。

## 5.6 みんチャレとの差別化（2026-07-04追記）

みんチャレ実態: 無料1チーム（10→3→1と段階縮小し反感）、月500円/年4,700円、40〜50代女性・ダイエット中心、写真報告→仲間のOK承認、自動退出機能、ロック領域への参入示唆なし、BtoB（46自治体・禁煙100法人・成果報酬）へ軸足。不満トップ3=写真報告ストレス/無料枠縮小の裏切り感/幽霊部員。

差別化軸:
1. 判定主体: 人間の承認(写真+OK) vs デバイスの自動判定 → 報告という作業が存在しない（ゼロ・レポーティング）。不満1・偽装懸念を構造で消す
2. 強制力: 励ましのみ（やらなくても何も起きない） vs 物理的結果（終わるまでTikTokが開かない）。ジョブが違う: みんチャレ=孤独の解、うち=意志力の外部化
3. ドメイン: みんチャレはスマホ依存を扱えない（スマホ外習慣の報告ツール）。うちはスマホ上で完結する問題のネイティブ解
4. 層: 40-50代女性 vs Z世代・受験生・#lockedin層（TikTokマーケと整合）
- 幽霊部員リスクは同型で残る → 定足数投票+時間帯マッチング+「退出でなく休眠→補充」（強制退出ショックの轍を回避）
- みんチャレのロック参入可能性は低（ユーザー層・API投資・BtoB方向）。「5人匿名×月500円が日本で成立」の市場実証として利用

## 5.7 マネタイズ詳細設計（2026-07-04追記）

ベンチマーク: H&F install→paid D35中央値2.9%（上位6.2%）、trial→paid 37.7%、APAC 2.4%。Productivityは月額偏重77%。日本発アプリは月300〜700円集中（みんチャレ500円アンカー）、海外ロック系は月1,000〜3,000円で通っている＝強制力への支払意欲は高い。

4層構造:
- L1 無料=ソーシャルコアループ全部（1スクワッド、1ロックルール、投票、ストリーク）。「コアは永久無料」を明言（みんチャレの縮小への反感を教訓に、後から絞らない）
- L2 Pro: 日本 月480円/年3,600円、グローバル $5.99/$39.99、LT 9,800円/$79.99。特典=複数スクワッド、複数ルール/カスタムスケジュール、Strictモード（解除チケット無効化）、全期間データ、詳細分析、シールドスキン、優先マッチング。トライアル7日
- L3 消耗: 緊急解除チケット（月1無料+追加¥160〜320、月3枚上限、使用はスクワッドに通知）、ストリーク保険（Duolingoフリーズ型、通知不要）。上限がある事自体が製品の誠実さ＝Strictモード有料と整合
- L4 後期: デポジット（Forfeit方式Stripe外部・寄付先選択でstickK型に、Phase 2以降）、塾・企業向けBtoB（Phase 3、みんチャレ実証ルートの翻訳）
- 試算: 10万DL×APAC中央値2.4%=有料2,400人×480円=月115万円。上位四分位なら月290万円

## 6. リスクと次の一手

市場構造: カテゴリ全体でVC調達$6M未満のブートストラップ市場。Opalは11人でARR $10M＝インディーで十分戦える。直接競合（Friend Controls 489レビュー、UseLess DL2.5万、LockPact新規）が小粒な今が先行者優位の残り時間。

1. **技術PoC**: DeviceActivityMonitor threshold→サーバー報告→push→ローカルシールドの一連を実機検証（シミュレータでは発火しない。threshold通知の遅延・早期発火バグはiOS 26.2でも未修正）。
2. **FamilyControls distribution entitlement早期申請**: ADPLA 3.3.3(P)の「対等な相互アカウンタビリティ」への運用解釈は申請してみるしか検証手段がない。LockPact承認の事実がポジティブ材料。
3. **MVPスコープ**: 招待コード（友人）＋匿名スクワッドマッチングの両輪、コア無料、課金は上記3層のうちサブスクのみから。
4. **競合ウォッチ**: UseLess / Friend Controls / LockPact の伸びとレビューを定点観測。
